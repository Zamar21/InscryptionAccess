# KNOWN_ISSUES.md

# Known issues in IKMA version 0.4.8 (beta)

This is Zamar's ongoing list. If you find something that is not here, please report it!
At any time during gameplay press Shift and the L key to send a log file to your desktop. Please send that log to the Inscryption text channel in Accessibility Disco, @ zamar, and give a brief description of what you found! 

## Install

- IKMA Manager is not code-signed, so Windows SmartScreen stops it the first time it runs. INSTALL.md explains the steps. The steps have not yet been confirmed with a screen reader.

## Speech and braille

- Braille output has not been confirmed on a real display. Each new line replaces the one before it, so in fast battle text the display shows the newest line. The review history (Control plus Up and Control plus Down) is how to step back.
- Speech timing under NVDA is estimated from line length, not measured. If a line seems cut off or a pause seems too long, a bug report with the log helps.
- Only SAPI and NVDA have been tested currently.

## Language

- English is currently the only supported language. The Language setting says "Feature coming soon."

## Not in this release

- The story acts, languages other than English, and more!
